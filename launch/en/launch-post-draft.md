# Launch post draft

## Title

I turned my Sims 4 Mods cleanup workflow into an open-source tool

## Draft

Most Sims 4 players do not need another downloader. They need a safer way to understand what is already in their Mods folder.

This project is being built around five rules:

```text
No blind deletion
No silent overwrite
Preview every action
Record every change
Make every run reversible
```

It will support English and Simplified Chinese, preserve original creator filenames, and generate an anonymized report that an AI assistant can help explain.

The project is currently under development. Repository link to be added at release.
