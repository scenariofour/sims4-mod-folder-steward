# Roadmap

## v0.1.0-beta

- Read-only scan
- Exact duplicate detection
- Same-name different-content review
- ts4script depth check
- Archive detection
- Inbox import
- Safe ZIP extraction
- Dry-run plan
- Quarantine
- Undo
- HTML, CSV, JSON and TXT reports
- Anonymous AI handoff
- English and Simplified Chinese
- English, Chinese and neutral folder profiles
- Windows and macOS support
- Three-page PySide6 desktop GUI
- Drag-and-drop Mods, Inbox, ZIP, package and ts4script input
- Optional complete Mods backup
- Single anonymized AI check ZIP

## Later

- Additional archive support
- Community folder profiles
- Signed release builds
- Optional local version notes
- Better creator and project grouping without renaming source files

## Out of scope for v0.1

- Downloading from creator websites
- Bypassing paywalls or login pages
- Uploading user inventories
- Reading Saves
- Automatically claiming a file is the latest public version
- Permanent deletion
