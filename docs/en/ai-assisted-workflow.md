# AI-assisted workflow

Select **Let AI help check updates** to copy a safe instruction, then **Export AI check ZIP**. Attach
that one ZIP to an AI assistant; there is no API setup in the app.

An AI or agent may use its own browsing tools to investigate creator pages and candidate versions.
It should return evidence, source links, uncertainty, and suggested candidates—not executable file
commands. If the user authorizes a download, put it in Inbox and run the local check again.

The AI must never receive real mod contents or credentials, claim a version is current without
evidence, recommend permanent deletion, or bypass the local Planner and whole-Plan approval.
