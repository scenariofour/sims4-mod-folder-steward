# Folder system

The tool uses stable category IDs and localized display names.

Original creator folders and mod filenames remain unchanged.

Example:

```text
10_CORE/
└── OriginalCreatorDownloadFolder/
    ├── original.package
    └── original.ts4script
```

The user may switch the outer category to Chinese:

```text
10_核心依赖/
└── OriginalCreatorDownloadFolder/
    ├── original.package
    └── original.ts4script
```

The inner names do not change.
