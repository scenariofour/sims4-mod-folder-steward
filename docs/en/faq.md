# FAQ

## Does it download or update mods?

No. The project has no network or login feature. An external agent may research or download only
with the user’s authorization; every candidate must return through Inbox and the local Plan.

## Does it delete old mods or backups?

No permanent deletion exists. Replaced originals and exact duplicate copies move into a reversible
run backup. The GUI never offers backup deletion.

## What happens to unknown files?

Unknown current files stay exactly where they are. Unknown Inbox files remain in the run review area
and are not installed.

## Can it identify the newest version?

Not from a filename. The AI ZIP can support outside research, but uncertain results stay uncertain.

## Can Undo overwrite a file I changed later?

No. Undo verifies hashes and stops when a current or backup path no longer matches its manifest.

## Does folder language rename creator files?

No. It affects only tool-created outer suggestions. Original filenames and creator folders remain.
