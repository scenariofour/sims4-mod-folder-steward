# Privacy

The app works locally and makes no network requests. It has no analytics, account, AI key, login,
MCP client, updater, or automatic downloader.

The AI check ZIP contains only these anonymized outputs:

- `AI_HANDOFF.md`
- HTML, JSON, text, and CSV scan reports
- `AI_PROMPT.txt`

Absolute home, workspace, Mods, and run paths plus the local username are replaced with placeholders.
The bundle contains filenames and hashes needed for review, but never mod file contents, credentials,
manifest operations, quarantine files, or complete backups. Export is a local save operation; the
user chooses whether and where to upload it.
