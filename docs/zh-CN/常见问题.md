# 常见问题

## 它会下载或更新 Mod 吗？

不会。项目没有网络或登录功能。外部 Agent 只有在用户授权时才能调查或下载；所有候选文件都必须
回到 Inbox，再由本地 Plan 验证。

## 它会删除旧 Mod 或备份吗？

不会永久删除。被替换原文件和完全重复副本进入可恢复的本次备份，GUI 永远没有删除备份按钮。

## 未知文件怎么办？

当前未知文件原地保持不变；Inbox 未知文件留在本次待检查区，不会安装。

## 它能判断最新版吗？

不能只看文件名判断。AI 检查 ZIP 可以用于外部调查，但不确定结果仍会标记为不确定。

## Undo 会覆盖我后来改过的文件吗？

不会。Undo 会核对哈希；当前路径或备份与 manifest 不一致时会停止。

## 分类语言会改作者文件名吗？

不会。语言只影响工具创建的外层建议，原文件名和作者文件夹保持不变。
