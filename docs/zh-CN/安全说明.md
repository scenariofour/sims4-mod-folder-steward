# 安全说明

GUI、CLI 和 Agent 入口共用同一套本地 Scanner、Planner、Executor、Quarantine 与 Undo 服务。

执行前，引擎会一次检查全部来源、目标、符号链接组件、SHA-256、路径冲突和隔离位置；任何已批准
操作未通过前，都不会开始修改 Mods。

执行时：

- 完全重复副本移入本次备份，并至少保留一份相同文件
- 替换前先将当前原文件移入隔离区
- 安装遇到已有目标会拒绝执行
- 每项完成后立即保存 manifest
- 权限错误或中断会触发逆序恢复

执行后会再次扫描。Undo 会核对当前文件和备份哈希，逆序恢复，并拒绝覆盖已占用或后来修改的路径。
可选完整备份只复制仍与扫描一致的普通文件；发现符号链接会停止。

项目没有永久删除服务，所有读写边界都排除 `Saves`。
