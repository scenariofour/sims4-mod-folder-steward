# 项目文件说明

## 根目录

- `README.md`：英文项目首页
- `README.zh-CN.md`：简体中文首页
- `LICENSE`：MIT License
- `ARCHITECTURE.md`：内部结构和路径边界
- `ROADMAP.md`：版本计划
- `SECURITY.md`：安全问题提交方式
- `CONTRIBUTING.md`：贡献规则
- `pyproject.toml`：Python 项目配置
- `AGENTS.md`：Agent 共用引擎与安全规则
- `packaging/`：PyInstaller 入口、跨平台 spec 和打包说明

## 程序

- `src/s4mod/`：程序代码
- `src/s4mod/gui.py`：三页 PySide6 入口
- `src/s4mod/workflow.py`：CLI/GUI 共用运行编排
- `src/s4mod/backup.py`：可选完整 Mods 备份
- `src/s4mod/ai_bundle.py`：匿名化单一 ZIP 导出
- `locales/`：界面翻译
- `folder_profiles/`：外层分类名称配置

## 文档和 Prompt

- `docs/en/` 与 `docs/zh-CN/`：用户文档
- `prompts/en/` 与 `prompts/zh-CN/`：安全的 AI Prompt

## 测试和自动化

- `tests/`：只能使用虚构文件
- `.github/workflows/`：自动测试
- `.github/workflows/package.yml`：Windows/macOS 原生打包
- `.github/ISSUE_TEMPLATE/`：问题提交模板
