# 开始使用

## 桌面程序

1. 打开 **Sims 4 Mod Folder Steward**。程序会在常用 Documents、iCloud 或 OneDrive 位置寻找
   名为 `Mods` 的文件夹。
2. 如果自动结果不对，直接拖入正确的 `Mods`，或点击选择文件夹。
3. 可选：继续拖入 Inbox 文件夹、ZIP、`.package` 或 `.ts4script` 候选文件。
4. 选择界面语言和外层分类语言；“保持当前结构”不会建议本地化外层文件夹。
5. 点击“检查我的 Mods”。这一步对 Mods 只读。
6. 只看三组结果。当前未知文件保持原位；Inbox 未知文件留在本次待检查区。
7. 如需外部调查，只导出一份 AI 检查 ZIP；程序不会自动上传。
8. 查看数量，可选完整 Mods 备份并确认预计空间。
9. 点击“批准整份 Plan 并开始整理”一次。即将改变的原文件会先进入备份。
10. 需要时点击“撤销本次操作”。如果文件后来被改过，Undo 会停止而不是覆盖。

GUI 永远不提供永久删除备份功能。

## 终端与 Agent

`s4mod run` 只生成 Plan，不修改 Mods。阅读 Plan 后才使用 `--apply`，并准确输入批准短语。
Agent 边界参见 [`AGENTS.md`](../../AGENTS.md)。
