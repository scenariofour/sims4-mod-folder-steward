# 文件夹分类说明

工具使用固定 category ID，同时允许外层分类显示中文或英文。

作者原始文件夹和 Mod 文件名保持不变。

英文分类示例：

```text
10_CORE/
└── OriginalCreatorDownloadFolder/
    ├── original.package
    └── original.ts4script
```

中文分类示例：

```text
10_核心依赖/
└── OriginalCreatorDownloadFolder/
    ├── original.package
    └── original.ts4script
```

里面的原始名称不会改变。
